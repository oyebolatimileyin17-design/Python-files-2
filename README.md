# Expense Tracker

A command-line Python program for logging personal expenses, viewing them, and seeing spending totals by category. Data is saved to a JSON file so it persists between runs.

## Features
- Add an expense (amount + category)
- View all logged expenses
- View total spending and a breakdown by category
- Saves and loads automatically using `expenses.json`

## How to Run
```bash
python "Day 27-30 project.py"
```

## Menu Options
1. Add Expense
2. View All Expenses
3. View Summary
4. Save & Quit

Capstone project for a 30-day Python course, combining classes, file I/O, JSON persistence, error handling, and a menu-driven CLI.
